ADMIN PAGE
- Route: /admin
- Password gate using env variable VITE_ADMIN_PASSWORD
  default password: minimal2025
- Upload form:
  - Drag & drop image with live preview
  - Wallpaper name (text input)
  - Category (free text input with suggestions:
    Minimalist, Japan, Cozy, Nature, Pastel, Anime, 
    Sunset, Architecture, Couple, Calm, Aesthetic)
  - Price (number input, default 4)
  - Featured toggle
- Save image to Supabase Storage bucket "wallpapers"
- Save data to Supabase table "wallpapers" with columns:
  id, name, category, price, image_url, featured, created_at
- Show grid of all wallpapers with edit, delete, 
  featured toggle buttons

SUPABASE
- VITE_SUPABASE_URL from env
- VITE_SUPABASE_ANON_KEY from env
- Fetch all wallpapers dynamically
- iPhone mockup cycles through featured wallpapers

STRIPE
- VITE_STRIPE_PUBLISHABLE_KEY from env
- All buy buttons open Stripe Checkout
- Currency: USD
- /success page after payment
- Cancel redirects to homepage

ROUTING
- react-router-dom
- /admin protected route
- vercel.json at root:
  {"rewrites": [{"source": "/(.*)", "destination": "/index.html"}]}

BUILD
- Single package.json at root (NOT monorepo)
- Build command: "vite build"
- Output: dist folder
- Must pass "npm run build" cleanly
